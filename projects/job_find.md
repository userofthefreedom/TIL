# 채용 공고 자동 수집기

## 한 줄 소개

사람인 스크래핑과 원티드 API를 함께 사용해 채용 공고를 수집하고, 조건에 맞게 필터링해 텍스트 파일로 정리하는 Python 자동화 toy project입니다.

| 기준 자료 | README, 공개 커밋 기록 |

## 문제 정의

채용 정보를 여러 플랫폼에서 반복적으로 확인하는 일은 시간이 많이 들고, 관심 조건과 맞지 않는 공고를 걸러내는 과정도 번거롭습니다. 이 프로젝트는 여러 소스의 공고를 수집하고 조건 기반 필터링을 적용해 확인할 목록을 자동으로 만드는 것을 목표로 했습니다.

## 주요 기능

- 사람인 스크래핑 기반 채용 공고 수집
- 원티드 API 기반 채용 공고 수집
- 제목, 직무 태그, 지역, 경력 조건 필터링
- 제외 단어와 X 마커 기반 공고 관리
- `output/jobs_all.txt` 형식으로 결과 저장
- Windows 작업 스케줄러 등록 가이드

## 기술 스택과 사용 이유

| 기술 | 사용한 이유 |
| --- | --- |
| Python | 수집, 필터링, 파일 출력 자동화 구현 |
| scraping / API | 서로 다른 채용 데이터 소스를 함께 활용 |
| config.ini | 검색 조건을 코드 수정 없이 조정 |
| Windows 작업 스케줄러 | 반복 실행 자동화 |

## 배운 점

- 자동화 도구는 “한 번 실행”보다 반복 실행과 설정 변경 편의성이 중요하다는 점
- 플랫폼마다 지역, 직무, 경력 표현 방식이 달라 필터링 규칙을 유연하게 설계해야 한다는 점
- README에 설치, 실행, 출력 형식, 스케줄러 등록을 적어야 나중에 다시 사용하기 쉽다는 점
