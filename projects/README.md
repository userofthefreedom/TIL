## 작성 기준

- 프로젝트 README와 공개 GitHub 커밋 기록을 기준으로 초안을 작성합니다.
- 커밋 메시지만으로 확정하기 어려운 내용은 `확인 필요`로 남깁니다.
- 단순 기능 목록보다 문제 정의, 구현 과정, 배운 점, 다음 개선 방향을 함께 기록합니다.
- 기술 스택은 GitHub language 통계와 README 내용을 함께 참고합니다.
