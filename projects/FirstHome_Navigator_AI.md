# FirstHome Navigator AI

## 한 줄 소개

첫 주택 마련을 준비하는 사용자가 청약 공고, 자금 계획, 금융상품, 지도, 커뮤니티, AI 코치를 한 흐름에서 확인할 수 있도록 만든 청약 큐레이팅 서비스입니다.

## 문제 정의

청약 정보는 공고문, 자격 조건, 자금 일정, 주변 위치, 금융상품 정보가 흩어져 있어 사용자가 자기 조건에 맞는 선택지를 판단하기 어렵습니다. 이 프로젝트는 사용자의 조건을 기준으로 청약 후보와 자금 준비 방향을 계산하고, 공식 근거와 AI 코치 설명을 함께 제공하는 것을 목표로 했습니다.

## 주요 기능

- 사용자 조건 입력과 프로필 기반 추천
- LH 청약 공고, 주택형 옵션, 공식 PDF 분석
- 자격, 자금, 지역, 일정 기준 추천 점수 계산
- 계약금, 중도금, 잔금, 부족액 기반 자금 로드맵
- 금융상품 비교와 추천
- Kakao Map 기반 위치 확인, 주변 은행/부동산 검색
- AI 코치와 전역 챗봇
- Swagger/OpenAPI, 제출 산출물, 화면 캡처 문서화

## 내가 작업한 것

- 사용자의 조건을 입력받아 청약 추천과 자금 계획으로 연결하는 서비스 흐름 설계
- 청약 추천 점수와 금융상품 추천 기준 설계
- 공식 PDF, fixture, 외부 API를 함께 쓰는 데이터 보강 전략 구성
- AI 코치와 챗봇의 fallback 구조 설계
- Swagger, ERD, API 흐름도, 캡처 산출물 등 제출 문서 정리

## 배운 점

- 실제 데이터는 완전하지 않기 때문에 rule-first, fixture 보강, 공식 근거 표시가 함께 필요하다는 점
- 추천 서비스는 점수 계산보다 “왜 추천됐는지”를 설명하는 구조가 중요하다는 점
- AI 기능은 실패 가능성을 전제로 fallback과 안전한 표현 제한을 설계해야 한다는 점
- 프로젝트 마감에는 기능 구현만큼 문서, 시연 안정성, 화면 가시성이 중요하다는 점

## 다음 개선 방향

- 추천 점수 산식을 사용자 피드백 기반으로 조정
- 공고 PDF 분석 결과의 신뢰도와 추출 근거를 더 세밀하게 표시
- 배포 환경을 ngrok 임시 배포에서 안정적인 클라우드 배포로 전환
- 테스트 코드와 API schema 검증을 CI에 연결
