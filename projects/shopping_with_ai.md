# AI 쇼핑 어시스턴트

## 한 줄 소개

AI와 Harness 구조를 활용해 사용자의 쇼핑 요구를 분석하고 상품 탐색/추천 흐름을 실험한 Python 기반 toy project입니다.

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| GitHub | https://github.com/userofthefreedom/shopping_with_ai |
| 형태 | 개인 toy project |
| 역할 | 서비스 기획, 기능 정의, 프로토타입 구현 |
| 주요 기술 | Python, Dockerfile, Gradio, API 연동, Harness |
| 기준 자료 | GitHub 프로필 README, 프로젝트 README, 공개 커밋 기록 |

## 문제 정의

온라인 쇼핑에서는 사용자의 요구가 모호한 경우가 많고, 상품 탐색 과정이 반복적입니다. 이 프로젝트는 사용자의 요구를 구조화하고, API나 도구 호출을 통해 상품 후보를 탐색한 뒤 추천 형태로 정리하는 실습형 프로토타입으로 보입니다.

## 주요 기능

- 사용자 요구 분석
- 상품 탐색과 추천 흐름
- API key 기반 외부 쇼핑 데이터 연동
- Gradio UI 기반 빠른 프로토타입 실행
- 성능/품질 기준과 개발 히스토리 문서화
- Docker 또는 WSL2 기반 실행 환경 준비

## 기술 스택과 사용 이유

| 기술 | 사용한 이유 |
| --- | --- |
| Python | 추천 로직, API 연동, 자동화 흐름 구현 |
| Gradio | 빠른 데모 UI 구성 |
| Docker / WSL2 | 실행 환경 재현과 의존성 관리 |
| Harness | Phase 기반 구현과 검증 흐름 실험 |

## 배운 점

- AI 기능을 서비스로 만들 때는 프롬프트보다 입력 구조, 후보 데이터, fallback이 더 중요하다는 점
- 작은 toy project라도 실행 환경, API key, 테스트 방법을 README에 정리해야 재현 가능성이 높아진다는 점
- Phase 기반 개발은 기능이 빠르게 늘어날 때 범위와 완료 기준을 유지하는 데 도움이 된다는 점
