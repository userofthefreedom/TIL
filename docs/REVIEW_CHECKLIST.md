# 학습 노트 리뷰 체크리스트

정리한 문서를 다시 볼 때 사용하는 체크리스트입니다.

## 구조

- [ ] 제목 계층이 `#`, `##`, `###` 순서로 자연스럽다.
- [ ] 문서 앞부분에서 이 주제가 무엇인지 바로 알 수 있다.
- [ ] 긴 문서에는 Quick Navigation 또는 핵심 목차가 있다.
- [ ] 관련 폴더나 문서로 이동할 수 있는 링크가 있다.

## 내용

- [ ] 개념 설명이 내 말로 정리되어 있다.
- [ ] 예시 코드가 너무 길지 않고 핵심을 보여준다.
- [ ] 실수하기 쉬운 포인트나 오류 사례가 남아 있다.
- [ ] 외워야 할 내용과 이해해야 할 내용이 구분되어 있다.

## 코드

- [ ] 코드 블록에 언어가 지정되어 있다.
- [ ] 실행 결과가 중요한 예시는 출력 예시가 함께 있다.
- [ ] 보안상 공개하면 안 되는 값은 포함되어 있지 않다.
- [ ] 실습용 로컬 경로나 임시 파일명이 그대로 남아 있지 않다.

## 마무리

- [ ] 마지막에 한 줄 요약 또는 정리 기준이 있다.
- [ ] 나중에 다시 봐도 바로 적용할 수 있는 형태다.
- [ ] README 목차나 루트 링크가 필요한 경우 갱신했다.
